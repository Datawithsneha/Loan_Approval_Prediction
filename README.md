# 🏦 Loan Approval Prediction Web App — End-to-End ML Application

**Tech Stack:** Python, Pandas, Scikit-Learn, Streamlit

* Performed exploratory data analysis (EDA) and data preprocessing on 614 loan applications, handling missing values via mode/median imputation and analyzing key approval drivers like Credit History and Property Area.
* Engineered binary and One-Hot Encoded features (`drop_first=True`) and applied `StandardScaler` post train-test split to prevent data leakage.
* Trained and evaluated a Logistic Regression classifier, achieving **78.86% test accuracy** in predicting loan eligibility.
* Developed and deployed an interactive real-time prediction web app on Streamlit Cloud for instant applicant assessment.

🔗 **Live App:** https://sneha-loan-predictor.streamlit.app/
